# Документация: MUN Badge Studio

Это приложение для создания бейджей конференций Модели ООН (MUN) с использованием искусственного интеллекта Google Gemini.

---

## 🛠 Технологический стек
- **React 19**: Основа интерфейса.
- **Vite**: Сборщик проекта (быстрый запуск и обновление).
- **Tailwind CSS**: Стилизация через CSS-классы.
- **Google Gemini API**: Генерация идей (Flash) и изображений (Flash Image).

---

## 📂 Структура файлов

- `index.html`: Главный HTML-файл. Здесь подключаются шрифты из Google Fonts.
- `index.tsx`: Точка входа в приложение (монтирует React-компонент).
- `App.tsx`: Основная логика. Здесь хранятся данные бейджа (состояние) и боковая панель управления.
- `components/BadgePreview.tsx`: Компонент отрисовки бейджа. Если нужно изменить макет самого бейджа — вам сюда.
- `services/geminiService.ts`: Настройки нейросети. Здесь можно поменять промпты (инструкции) для ИИ.
- `types.ts`: Определения типов (список ролей, структура данных).

---

## 🎨 Как внести изменения

### 1. Как добавить новую Роль (Role)
Откройте файл `types.ts` и добавьте новое значение в `enum BadgeRole`:
```typescript
export enum BadgeRole {
  DELEGATE = 'Delegate',
  OBSERVER = 'Observer', // Добавлено
}
```

### 2. Как изменить макет бейджа
Откройте `components/BadgePreview.tsx`. 
- Бейдж — это `div` с фиксированными размерами (`w-80 h-[480px]`).
- Для изменения цветов используются inline-styles: `style={{ backgroundColor: data.primaryColor }}`.
- Для изменения положения элементов используются классы Tailwind (например, `absolute top-10 left-10`).

### 3. Как настроить шрифты
1. Добавьте ссылку на шрифт в `index.html` (Google Fonts).
2. В `App.tsx` добавьте название шрифта в массив `AVAILABLE_FONTS`.
3. В `components/BadgePreview.tsx` добавьте его в функцию `getFontClass`, чтобы привязать CSS-класс.

### 4. Как изменить инструкции для ИИ (Prompts)
Откройте `services/geminiService.ts`.
- В функции `getBadgeDesignIdeas` можно изменить текст `prompt`, чтобы ИИ давал другие советы.
- В функции `generateVisualReference` можно изменить промпт для генерации картинки (например, добавить "photorealistic" или "flat design").

## ⚠️ Важные правила Gemini API
При работе с `@google/genai` в этом проекте:
- Ключ API берется автоматически из `process.env.API_KEY`.
- Не создавайте экземпляр `GoogleGenAI` глобально, делайте это внутри функций (как в `geminiService.ts`), чтобы избежать ошибок при загрузке страницы.
- Для генерации текста используйте модель `gemini-3-flash-preview`.
- Для генерации изображений используйте модель `gemini-2.5-flash-image`.

## ❓ Часто задаваемые вопросы

**Как изменить размер бейджа для печати?**
Бейдж сверстан в пропорциях стандартной карты. Если нужно увеличить его визуально, измените ширину (`w-80`) и высоту (`h-[480px]`) в `BadgePreview.tsx`, но помните, что это изменит масштаб всех вложенных элементов.

**Почему не генерируется изображение?**
Проверьте консоль браузера (F12). Скорее всего, превышен лимит запросов API или не задан API_KEY в окружении.
